# Machine Learning From Scratch 🚀

## 📌 Overview

This repository is created as part of my **Machine Learning learning journey**, where I implement **core ML algorithms from scratch** to deeply understand how they work internally instead of just using libraries.

The focus of this repository is **conceptual clarity + coding from first principles**. I will continuously add more algorithms and techniques as I progress in Machine Learning.

---

## 🎯 Goals of This Repository

* Learn Machine Learning **by implementation**, not just theory
* Build ML algorithms **from scratch using Python**
* Understand the **mathematics, logic, and flow** behind each algorithm
* Create reusable **custom classes** similar to `scikit-learn`
* Maintain clean, well-structured, and readable code

---

## 📚 Topics Covered (So Far)

### ✅ Linear Regression

Implemented **from scratch**, including:

* Simple Linear Regression
* Multiple Linear Regression
* Cost Function (MSE)
* Gradient Descent
* Model training and prediction

### ✅ Types of Linear Regression

* Batch Gradient Descent
* (Upcoming) Stochastic Gradient Descent (SGD)
* (Upcoming) Mini-batch Gradient Descent

### ✅ Principal Component Analysis (PCA)

Implemented from scratch to understand:

* Dimensionality reduction
* Mean centering
* Covariance matrix
* Eigenvalues & eigenvectors
* Feature transformation
* Variance retention

---

## 🧠 Learning Approach

Each algorithm is:

* Implemented **step by step**
* Written using **custom Python classes**
* Explained with comments for better understanding
* Designed to mimic real ML libraries (e.g., `.fit()`, `.predict()`)

This repository is **not about performance**, but about **learning how ML works internally**.
